# CoreGenie 2026 年 9 月更新

## 从提案资料到分析报告与汇报 PPT

准备一次提案讨论，往往需要找资料、读原文、比较方案，再把要点整理成汇报材料。这次更新围绕这些日常工作，新增提案 PPT 生成、两次会议的提案对比和公共知识库，也让任务发起、进度查看和文件整理更方便。

**更新范围：2026 年 9 月 21—29 日。**

## 本次亮点

### 提案可以整理成汇报 PPT 了

把单份或一批 DOCX 提案交给助手，就可以围绕提案要点、关键图表和方案差异，整理一份中文汇报 PPT。

生成的 PPTX 支持继续编辑，表格可以直接修改；使用的原图会保留比例，相关内容附有原文出处。你可以在此基础上调整重点、补充自己的判断，用于会议准备和团队讨论。


### 比较两次会议，看清提案有哪些变化

除了分析单次会议，现在也可以比较前后两次会议的提案：哪些内容延续了下来，哪些方案进行了调整，又新增了哪些技术内容。

助手会先梳理提案之间的修订关系，再逐项比较。提供本方的关注点或立场材料后，还可以进一步整理相关提案与本方观点的差异。资料不足的地方会单独说明，方便后续补充。


### 跟着快捷任务，更容易开始分析

不必每次都从头组织一段长提示词。通过快捷任务，可以按 TDoc 编号或会议议题发起任务，选择工作组、会议和 KI，再补充你希望关注的内容。

任务可以只下载资料，也可以下载后继续分析。会议支持搜索、按年份浏览和多选；已收录的 KI 提供中文简述，方便选择。填写完成后，你可以检查、修改生成的任务描述，再添加到聊天草稿，由你确认发送。


### 公共资料上传一次，多个工作区都能使用

新增公共知识库。常用标准资料、术语说明和团队参考文档可以集中维护，在不同工作区的问答与分析中检索使用，减少重复上传和整理。

资料列表支持查看、下载和移除。加入公共知识库的内容会参与所有工作区的检索，适合放置可供成员共享的材料。


## 日常使用更顺手

### 任务做到哪一步，看得更清楚

新增任务计划卡片，展示处理步骤、当前状态和完成数量。读取文件、下载提案等工具活动也有了更清楚的说明，可以展开查看细节。等待较长任务时，更容易了解助手正在处理什么。


### 资料和结果，在工作区里继续整理

工作区文件管理支持目录浏览、上传、预览、重命名和删除，也可以将整个文件夹打包下载。原始材料、分析报告和汇报文件放在同一个工作区，便于查看、整理和继续使用。


### 批量转换，保留已完成的结果

完善 DOCX 批量转 Markdown 流程，将正文、原图和嵌入对象一起整理成文件包。转换结果会列出成功项、失败项和需要注意的格式问题；某个文件失败时，其余已完成的结果仍会保留，后续可以只重试失败文件。

### 部署与配置

- **新增离线部署包工具**：支持打包应用及所需组件，并迁移全局配置、Agent、Skill 和公共资料，方便在受限网络环境中安装。工作区资料和聊天记录不包含在这类全局数据迁移中。
- **快捷任务可以统一管理**：管理员可以创建、编辑、预览快捷任务，并绑定到需要使用的 Agent；同一个任务可以复用。
- **对话命名可以使用独立模型**：支持为自动生成对话标题配置轻量任务模型，不影响聊天和 Agent 使用的模型。
- **镜像更新更方便**：补充镜像更新脚本与部署说明，完善代理环境和数据库连接配置的处理。

## 问题修复与兼容性调整

### 任务执行与模型接入

- 修复未显式指定运行编号时，任务恢复记录可能使用空编号的问题。
- 修复用户回答助手的补充问题后，任务恢复时可能被误判为“没有进展”的问题。
- 完善子任务的独立运行记录，保存完成状态、返回内容和具体错误，便于查看执行结果。
- 修复部分 OpenAI 兼容模型未返回消息角色时，流式回复无法正常处理的问题。
- 修复上述兼容场景下，分段返回的工具调用信息可能丢失、影响工具执行的问题。
- 保留兼容模型返回的推理信息，避免信息丢失影响后续处理。

### 提案读取与文档处理

- 修复 TDoc 编号与下划线等文件名字符相邻时，部分编号无法正确识别的问题。
- 修复议程项筛选使用部分字符匹配，可能误选相近编号的问题。
- 修复提取文档时遗漏大写 `.DOCX` 扩展名文件的问题。
- 跳过 Word 生成的临时锁定文件，避免将其作为正式提案解析。
- 完善单文件提取入口，直接指定 DOCX 文件时无需先整理成目录。
- 修复原图与正文位置对应不完整的问题，补充表格单元格内图片的位置记录。
- 避免同一图片的兼容格式在同一个正文块中被重复记为多张图。
- 完善批量转换中的同名文件处理，避免不同目录下的同名文件相互覆盖。
- 完善批量提取和转换的失败处理，逐项保存结果，保留已成功处理的文件及失败原因。
- 修复仅有文件标记、没有实际正文的提取结果可能被当作有效资料的问题。
- 修复重新检查资料失败后，旧的成功检查记录可能残留的问题。
- 补充正文变更检查，避免资料已经更新，报告保存到知识库时仍沿用旧的检查结果。

### 页面与日常交互

- 修复版本更新后，浏览器加载旧页面资源可能导致页面无法打开的问题。
- 为页面资源恢复增加重试间隔，避免同一页面短时间内反复刷新。
- 修复部分浏览器不支持富文本剪贴板或权限受限时，复制内容失败的问题；无法复制富文本时会尝试复制纯文本。
- 修复复制未成功时，界面仍可能显示“已复制”的问题。
- 改善新对话标题迟迟不更新的情况，先根据首条消息显示标题，再在后台生成简短名称。
- 修复后台生成标题与用户手动重命名同时发生时，手动标题可能被覆盖的问题。
- 避免并发请求重复生成同一对话的标题；模型调用失败或超时时保留已有标题。

### 配置迁移与部署

- 兼容旧版快捷任务表单，迁移时保留已有的自定义内容。
- 区分“没有修改任务绑定”和“主动清空绑定”，避免更新 Agent 时意外移除快捷任务。
- 完善共享任务及绑定数量的检查，配置不符合要求时避免只保存一部分改动。
- 修复应用启动后的请求配置可能覆盖代理设置，导致 3GPP 官方目录访问超时的问题。
- 修复更新容器时可能遗漏 PostgreSQL 连接配置、使应用连接到错误数据库的问题。

## 使用时请注意

- PPT 生成与排版检查需要对应的运行组件。缺少检查条件时，助手会说明哪些检查尚未完成，并将结果标为草稿。
- 当前批量 Markdown 转换主要支持 DOCX。旧版 DOC 需要额外的转换环境；PDF 和 PPTX 输入暂不支持这套完整转换流程。
- 提案中的公司主张与正式会议结论会分别说明。图表看不清或资料不完整时，助手会指出具体缺口。
- 离线部署包解决安装与迁移问题。访问官方资料和使用模型服务，仍需要目标环境具备相应的网络与服务条件。
