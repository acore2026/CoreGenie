# 实验首页设计

状态：独立交互原型，尚未接入服务端，也未替换现有首页。

参考：DeepSeek Harness `ddefc45fbc7f8e46dd73185e68295696d1297887` 中的 EmptyHero、InputBar、SidebarRoot。原型重新编写，使用 CoreGenie 现有标志，不引入 DSH 运行时或品牌。

## 使用场景与布局

面向阅读提案、比较方案和整理材料的研究人员。首页的主要动作是开始任务或继续最近对话。领域元素为提案、会议、TDoc、公司、资料、报告；项目特色是输入前可见的资料归属，以及任务示例与助手选择的关联。

采用纸白、浅灰、石墨色文字、青色操作提示、绿色完成状态和琥珀色等待状态。默认原型使用浅色，真实接入遵循用户现有主题偏好。保留现有字体体系；中文使用系统字体，不增加远程字体加载。复用现有边框层级，4px 间距基准；输入区为单一焦点，28px 标题、15px 输入正文、13px 控件、11px 元信息。

- 桌面：240px 导航，72px 顶栏；输入区最大 720px，随可用宽度收缩。
- 手机：768px 以下使用导航抽屉；20px 页面边距，无常驻右栏。
- 工作区选择紧贴输入区，明确新对话归属。工作区仍是权限和资料隔离单元，不改成文件系统目录。
- 三个轻量示例替代首页 Agent 卡片网格；示例只填入草稿并选择助手，不自动发送。
- 资料按需打开；原型用模态面板，真实首页第一版保持此形式。对话页文件与报告并排预览是后续范围。
- 不在首页增加指标卡、执行面板、插件清单。模型仍是工作区设置，不伪装成对话独立模型。

## 原型可操作项

导航折叠、手机导航、示例对话搜索、工作区选择、助手选择、示例填入、主题切换、添加/移除本地附件名称、资料入口、发送前预览。原型只保留页面内状态；不会上传文件、读取附件内容、请求模型或创建工作区。底部明确标记示例数据。

## 接入方案

建议增加独立 `/experimental/home` 路由，保留 `/`。新路由沿用 PrivateRoute；设置或账户菜单提供实验入口与返回入口，不改变默认首页。生产页面的所有文案放到 `frontend/src/locales/zh/common.js`。

使用 React + 现有 Tailwind/主题变量实施这一小范围实验。抽取轻量 HomeComposer 和通用 WorkspacePicker；首页不直接导入现有整个 PromptInput 依赖树。复用经过适配的附件上传、中文输入法和草稿逻辑，避免复制第二套会话运行逻辑。DSH 复杂 slots、Cordis、Dockkit 暂不进入首页。

首页输入在数据加载时即可编辑；工作区和权限未确认前禁用发送，并保留草稿。工作区列表为空时沿用当前角色规则：普通用户显示未分配提示，有权限者显式创建工作区。加载失败在控件附近显示具体原因和重试按钮。运行中的会话切换、停止与恢复继续使用现有机制。

点击发送后，先确保工作区、线程和附件状态正确，再通过当前 PENDING_HOME_MESSAGE 流程进入原会话页；此阶段允许页面切换，要求草稿仅发送一次。后续如改为同一页面从首页变成聊天，需要单独处理输入框挂载和会话订阅生命周期。

## 性能计划与验收

以下为设计目标，尚未测量，也不能以静态原型的速度证明生产性能。

1. 首页首屏不加载聊天历史渲染、Markdown/代码高亮、图表、文件预览、工具配置和模型供应商列表。用路由分包与动态导入确认网络行为；仅 CSS 隐藏不能算按需加载。
2. 工作区与 Agent 清单集中获取、缓存和去重。当前 Home 会获取工作区信息，侧栏另取列表，AgentShowcase 和 AgentSwitcher 又各自调用 usePredefinedAgent。新页面共享数据源，避免重复请求；切换账户清理缓存。
3. 最近对话按权限、更新时间获取有限一页；确认现有接口后决定是否补充聚合接口，不为首屏遍历所有工作区线程。移动端导航数据可在首次打开时获取。
4. 草稿输入仅更新输入组件；不让每个字符触发整个首页和历史列表更新。草稿持久化合并写入，在发送或离开时补写。
5. 资料列表和预览在打开时才请求；关闭停止相关订阅。删除首页常驻文件栏挂载带来的首屏文件请求。
6. 基线与实验页使用相同生产构建、账户、数据、设备和网络条件，分别进行冷启动与热启动对比，各运行至少五次并报告中位数及范围。

验收目标：生产环境 p75 INP ≤200ms、CLS ≤0.1、LCP ≤2.5s；实验室另记录输入/打开菜单响应、首屏 JS 传输与执行耗时、请求次数。初始 JS 压缩传输量相对旧首页降低 25% 作为待验证目标，不为了达标删减权限或上传功能。真实 INP 需要现场数据，不能用少量自动点击代替。

功能检查覆盖：中文输入法 Enter、示例不发送、附件未就绪不可发送、双击防重、工作区切换、无权限/无工作区/网络失败、草稿恢复、运行中会话导航、移动键盘、键盘焦点、浅深主题和减少动画偏好。
