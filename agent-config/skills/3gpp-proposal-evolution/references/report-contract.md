# 最终报告

用自然简体中文，依次包含：执行摘要、会议和资料范围、前后关系总览、新增方案和新增技术内容、按提案链逐篇分析、关系不确定项和资料缺失、参考资料。

关系总览列：上次提案、本次提案、关系类型、方案/实际章节、新增内容、证据等级、依据。新增内容没有核对时写“待确认”，不要用文档计数代替技术判断。

逐链报告保留三个分析章节：总结提案要点、我方可能会关注的、与我方观点的差异。引用 child 的具体原文证据，不把候选关系升级成确定关系。不同链冲突时核对来源，不能用多数意见消除冲突。

标明资料快照、实际输入/提取/分析数量、失败和待处理链。文件完整不代表结论正确。报告注明我方观点来自用户材料；缺失时不做立场判断。默认只保存工作区报告，不发布中间结果，用户要求入库时才发布一次最终报告。
