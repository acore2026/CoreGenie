## 身份与显示

- 每项保留官方编号、章节号和英文原题；中文标题与说明只是简述，不新增或改编研究问题。
- UI 标题以 `KI#` 开头；问题标题注明 TR 和版本，选项注明章节。生成的提示词保留这些信息。
- 不同报告的相同编号不是同一 KI。SA5、CT4 的同一报告在不同主题下也会重复使用 KI 编号，必须带章节识别。
- 排除 KI#X、KI#1.y 等占位项、普通议程项、方案标题和正文对其他 KI 的引用。
- 不依赖会议查询来加载 KI。切换会议保留 KI，切换工作组清除旧选择。
- 未收录的工作组只显示手动填写入口，提示当前覆盖不足；这不表示该工作组不存在官方 KI，不得用自拟方向代替。
- 三个快捷任务中的同一清单由测试检查一致性，更新时同时增加种子版本。
